# ☕ Journey With Java

- Welcome to **Journey With Java**! 

- I created this repository to document my Java learning journey, starting with basic programming concepts and gradually progressing towards more advanced problems and coding techniques.

- I have organized my Java programs into six levels, with each level focusing on different concepts. Through these programs, I practise writing code, improve my logical thinking, and learn different approaches to solving programming problems.

## 📚 What I've Learned

### 🔹 Level 01 – Java Fundamentals
- Hello World and user input
- Variables, data types, and basic operations
- Addition, subtraction, multiplication, and division
- Quotient, remainder, and swapping numbers
- Squares, cubes, and powers
- ASCII values and mathematical calculations
- Simple interest and compound interest

### 🔹 Level 02 – Conditional Statements
- Checking even and odd numbers
- Identifying positive, negative, and zero values
- Finding the largest and smallest numbers
- Using the ternary operator
- Leap year checking
- Grade calculation based on marks
- Building a simple calculator
- Identifying vowels, consonants, and character types
- Checking uppercase and lowercase characters

### 🔹 Level 03 – Loops and Number-Based Problems
- Printing numbers within a range
- Generating even and odd numbers
- Multiplication tables
- Calculating factorials
- Finding the sum of natural, even, and odd numbers
- Reversing numbers and checking palindromes
- Generating the Fibonacci series
- Checking prime numbers and Armstrong numbers
- Checking perfect squares
- Calculating square roots and cube roots
- Finding the sum of digits

### 🔹 Level 04 – Arrays and Searching
- Finding the number of elements in an array
- Finding the largest and smallest array elements
- Calculating the sum and average of array elements
- Sorting arrays
- Implementing linear search
- Implementing binary search
- Identifying duplicate elements

### 🔹 Level 05 – Strings and Object-Oriented Programming
- Finding the length of a string
- Replacing characters in strings
- Finding the Greatest Common Divisor (GCD)
- Understanding classes and objects
- Working with constructors
- Method overloading and method overriding
- Understanding inheritance and its types
- Working with abstract classes and interfaces

### 🔹 Level 06 – Advanced Programming Practice
- Reversing strings
- Checking whether strings are anagrams
- Counting digits
- Converting binary numbers to decimal
- Finding the length of strings and checking empty strings
- Building a basic login system
- Removing spaces from strings
- Reversing arrays
- Identifying duplicate array elements
